# griffinbeels.github.io

The GitHub Pages site behind **[griffinbeels.github.io/miji](https://griffinbeels.github.io/miji/)** — Miji, a dictionary for iPhone that remembers for you. *Search once, remember forever.*

Nothing here is edited by hand: the `miji/` directory, `robots.txt` and `llms.txt` are generated from Miji's own repository (`site/copy.md` → `tools/site/build.py`) and pushed by `just site-deploy`.
